# My 페이지 UI

## 2026-11-06 · 내 팁 API 연결

`/my/tips`와 `/my/tips/[tipId]`는 My 예시 데이터 대신 팁 API를 사용한다. 목록(API-053)은 계약에 있는 ID·상태·등록 시각만 표시하며 사진·본문을 임의로 만들지 않는다. 커서 페이지와 추가 조회 실패 재시도, API-090의 최신 version을 이용한 원격 삭제를 제공한다.

편집(API-090·054)은 종류와 본문 필수·사진 선택·120자/LF 정규화 정책을 적용한다. 새 사진은 TIP_PHOTO 업로드 세션 → S3 binary PUT → 완료 확인 READY 후 연결하고, 기존 사진 제거는 빈 uploadIds로 보낸다. 본문·종류·사진만 수정하면 위치를 보내지 않는다. 현장 AR 재배치는 별도 진입에서 위치·새 공간 참조·배치를 모두 제공한다. 수정 진행 중에는 이전 공개본이 유지되며 API-050·051로 단계 확인과 재시도를 제공한다. 버전 충돌 시 최신 내용을 다시 확인하고, 결과가 불명확한 요청은 같은 멱등키로 확인한다.

아래의 My mock·preview 설명은 팁 목록/편집을 제외한 기존 화면의 이력이다. 현재 팁 화면의 로딩·빈·오류 상태는 MSW와 실제 Query 상태로 확인한다. 디자인은 기존 패턴을 유지했고 Pencil 노드가 없어 미대조다.

Figma My 영역(`gzYo8vG6h2LrKGOa22UCFP`, `20:4848`)을 참고한 UI 미리보기다. API 계약은 정의하지 않았다. Pencil 대응 아트보드는 없어 미대조이며 기존 디자인 토큰을 사용한다.

- 하단 **My** → 내 기록, 내 발자취, 내 팁, 계정 메뉴.
- 내 기록 전체 보기 → `/memo` 이동. 사용자 요청으로 `/memo` 페이지 자체는 아직 만들지 않았다. Expo의 생성 라우트 타입에 없는 예정 경로라 이동 지점에서 `Href`를 명시한다.
- 발자취: 기간·카테고리 필터, 지도 핀·행 선택, 방명록 본문 수정(200자).
- 팁: 예시 사진 4개, 종류·사진·내용 수정(120자), 삭제 확인·목록 반영·빈 상태.
- 계정: 로그아웃 확인 → 로그인 미리보기, 탈퇴 동의 → 본인 확인 미리보기 → 최종 확인 → 완료.

내 발자취·내 팁 목록에는 하단 시스템 안전 영역에 32pt를 더한 스크롤 여백을 둔다. 내 팁 빈 상태는 기존 96pt에 안전 영역을 더한다.

데이터는 `features/user/mocks/my-data.ts`, 화면 사이 상태는 `MyMockProvider`에서 관리한다. My 라우트가 유지되는 동안만 변경 내용이 남고 앱 재시작·My 라우트 제거 시 초기화된다. 실제 API·카카오 재인증·토큰 변경·계정 삭제·사진 권한 요청은 수행하지 않는다. 사진 선택은 로컬 예시 사진만 사용한다. 여행 기록 편집 화면은 이번 범위에 없으며 준비 중 안내를 표시한다.

Figma 예시의 방문 날짜를 유지했다. 기간 필터 기준일은 mock의 **2026-11-10**이며 실제 기기 날짜를 쓰지 않는다. 처음 3개월에는 3곳, 전체 기간에는 12곳이 나온다.

발자취와 방명록은 기존 `KakaoMapView`로 실제 카카오 지도를 띄운다. 좌표는 공개 장소 부근의 mock 값이며 실제 사용자 방문 위치가 아니다. 필터에 맞는 방문 위치를 모두 보이게 맞추고 발바닥 핀을 누르면 해당 방명록으로 이동한다. 방명록 지도는 선택한 한 곳을 확대해 표시한다. 위치 사이에 동선은 그리지 않으며 위치 권한이나 방문 기록 API를 호출하지 않는다. 기존 `EXPO_PUBLIC_KAKAO_JAVASCRIPT_KEY`를 사용하고 로딩·오류·재시도를 제공한다. 웹에서는 앱에서 확인하라는 안내를 표시한다.

지도 회귀 검사: `node scripts/check-footprint-map.cjs`.

발자취 클러스터는 Figma 지도 발자취 영역(`20:4585`)의 큰 마커(`20:4602`)를 참고해 70×80 크기 안에 발바닥(55×55)과 하단 코랄 숫자 배지를 표시한다. 숫자는 묶인 발자취 개수이며 999를 넘으면 `999+`로 표시한다. 개별 핀은 기존 크기를 유지하고 클러스터를 누르면 기존 카카오맵의 확대 동작을 따른다. 다른 지도 화면의 기본 클러스터 스타일은 유지한다.

사용자 조정(2026-11-06): 지도 높이는 내 발자취에서 기존 176pt의 1.3배(228.8pt), 방명록에서 기존 144pt의 1.5배(216pt)로 표시한다.

상태 확인: `/my`, `/my/tips`, `/my/footprints`에 `?preview=loading`, `?preview=error`, `?preview=empty`를 붙인다. 오류 화면의 재시도는 기본 화면으로 복귀한다. 팁·방명록 편집 경로의 `?preview=error`는 첫 저장만 실패시켜 입력 유지·재시도를 확인한다. 네트워크 요청을 흉내 내는 지연은 두지 않는다.

로그인 제공자는 실제 로그인 성공 시 로컬에 저장하며 My 프로필과 탈퇴 화면에서 함께 읽는다. 카카오는 카카오 안내·로고·버튼, 구글은 구글 안내·로고·버튼을 표시한다. 토큰 갱신 시 유지하고 세션 삭제 시 함께 지운다. 제공자 정보가 없는 기존 인증 세션은 임의로 추측하지 않고 본인 확인 버튼을 비활성화한다. 인증 세션이 없는 mock UI는 기본 카카오 프로필을 사용한다. `/my/preview-login`에서 선택한 제공자는 My mock 상태에만 반영하며 실제 인증 토큰은 바꾸지 않는다. 본인 확인·탈퇴는 여전히 UI 미리보기이며 실제 재인증·계정 삭제 API는 호출하지 않는다.
